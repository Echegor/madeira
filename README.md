# Madeira Island Master Expedition & Field Guide

An interactive, high-resolution editorial presentation deck and tactical field guide for a comprehensive 7-Day / 8-Night alpine and subtropical coastal expedition across **Madeira Island, Portugal** ("The Hawaii of Europe").

## Project Architecture
This repository adapts the presentation architecture from the [Fisherman's Trail Expedition](https://echegor.github.io/fishermans-trail/) into a dedicated expedition guide for Madeira.

* **`index.html`**: Complete single-file responsive presentation deck featuring dark/porcelain themes, mobile slide pickers, interactive cartography, and field protocols.
* **`MEMORY.md`**: Agent persistent state tracker and slide-by-slide completion checklist.
* **`HANDOFF_PROMPT.md`**: Master specification blueprint with detailed research and slide-by-slide requirements for building out the deck.

## Highlights Covered
* **High Mountain Peaks**: PR1 Pico do Arieiro to Pico Ruivo ridge trek above cloud inversions.
* **Emerald Levada Canyons**: PR9 Levada do Caldeirão Verde and PR6 25 Fontes.
* **Dramatic Coastlines**: PR8 Ponta de São Lourenço clifftops and Porto Moniz volcanic lava pools.
* **Mystical Heritage**: 500-year-old UNESCO Fanal Forest, Santana thatched palheiros, and Funchal's historic Monte toboggan.
